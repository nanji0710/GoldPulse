建议规则（参考口径）

趋势判定：取该品种近期行情序列，短期(近10点)与中期(近30点)涨幅同向判断—— ↑ 双升 看多，↓ 双跌 看空，否则 → 横盘。
组合规则（趋势 × 盈亏）：
 · 趋势↑ + 浮盈 → 持有：趋势向好，继续持有
 · 趋势↑ + 浮亏 → 买入：趋势回升，分批补仓摊薄成本
 · 趋势↓ + 浮盈 → 卖出：趋势转弱，考虑止盈部分
 · 趋势↓ + 浮亏 → 观望：趋势走弱且浮亏，谨慎观望
 · 横盘 → 持有：横盘震荡，持有观望
 · 点数 < 5 → 待积累：数据不足不生成建议
