## 3. 交互与视觉规范

### 3.1 价格头卡（实时）
- 数据源：`priceProvider` 流（非 DB），随轮询实时跳动
- 大字价格 `headlineLarge` + tabularFigures；涨跌胶囊复用 GoldCard 语言
- 状态胶囊复用 `MarketHours.label()/resumeHint()`
- 渐变背景复用 `AppTheme.heroGradient`（与首页卡片视觉延续）

### 3.2 区间统计行
- 数据源：当前周期加载的历史行
- 区间最高 / 区间最低 / 区间涨跌（首尾差%，红涨绿跌）
- 三列等宽，标题 `labelSmall` 次级色，数值 `titleMedium`

### 3.3 分段控件（周期）
- 胶囊容器（card 色，radius 999，内边距 4）
- 激活段：金底 alpha 0.16 + 金字；未激活：次级色
- 相邻段间距 ≥ 8px；整控件高 ≥ 44px（触控规范）
- K线：独立图标+文字胶囊（candlestick 图标），与周期**分离**

### 3.4 图表卡
- 容器：card 色 + radius 20 + padding 16
- **折线模式**（fl_chart 0.69）：
  - 左轴价格刻度：reservedSize 52，区间 4 档，`fmtPrice` 1 位小数
  - 底轴时间刻度：1日 → HH:mm；7日/30日 → MM-DD，约 4-5 档
  - 面积填充：gold → 透明 渐变（流式数据"历史淡出"规范）
  - 触摸提示：十字线 + 气泡（价格 + 时间），gold 主题色
  - 水平网格线：divider 色细线
- **K线模式**（CustomPaint）：
  - 增加水平网格线（divider 色）
  - 色盲友好：**涨=红实心，跌=绿空心（仅描边）**（图表规范：fill vs outline）

### 3.5 状态设计
| 状态 | 呈现 |
|------|------|
| 加载中 | 转圈 + "正在加载历史行情…"（卡片内） |
| 空态（无历史） | 图标 + "暂无历史数据，行情轮询启动后自动生成" |
| 有数据 | 图表 + 统计行 |

### 3.6 AppBar 刷新
- 刷新按钮：`ref.invalidate(priceProvider/accumulationPriceProvider)` + 重载历史
- 页面自身 watch `priceProvider` → 新价入库后图表自动跟随（半实时）
