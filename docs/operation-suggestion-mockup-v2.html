融合后的建议口径

置信度评分 0-100：今日涨跌 30% + 近期(最近可得窗口) 40% + 持仓状态(收益率) 30%；点数不足自动降级。
趋势：按当前价 vs 昨收、当前价 vs 近期窗口起点判断 ↑涨 / ↓跌 / →震荡。
持仓建议（收益率分档 × 趋势）：
 · 收益率 ≤ -15% → 风险提醒：亏损较大，重新评估仓位
 · -15% ~ -5%：趋势↑ → 分批补仓；趋势↓ → 观望等反弹
 · -5% ~ +5% → 观察/持有
 · +5% ~ +20%：趋势↑ → 持有；趋势↓ → 减仓止盈部分
 · > +20% 且短期涨幅大 → 分批止盈（卖出 20-30%）
多品种：主建议取信号最强烈（或风险最高）的品种，其余品种一行摘要。
防频繁提醒：一次建议 24h 内不重复变更（除非价格波动 >5% 或评分变化 >20）。
