# 常驻通知栏 设计文档

## 1. 目标

在 Android 通知中心常驻一条通知，持续显示**指定积存金**的成本变化与收益。用户可手动开关、选择品种、选择最多 4 个展示指标、设置刷新频率。

定位：常驻信息条，非打扰性提醒——用户下拉通知栏即可随时看到持仓行情，无需打开 App。

## 2. 用户配置（设置页新增「常驻通知栏」区块）

| 配置项 | 取值 | 说明 |
|---|---|---|
| 总开关 | 开 / 关 | 开 = 启动前台服务并显示常驻通知；关 = 停止服务、移除通知 |
| 显示品种 | 单选 | `au9999` / `accumulation` / `icbc` / `minsheng`（默认 `accumulation` 浙商积存金） |
| 刷新频率 | 5 / 10 / 30 / 60 秒 | 默认 10 秒；独立于行情轮询频率 |
| 展示指标 | 8 选 4（最多 4） | 默认：均价(成本)、持仓收益、收益率、今日盈亏 |

**指标池（8 个，用户从中选最多 4 个）：**

| # | 指标 | 计算口径（与资产页一致） |
|---|---|---|
| 1 | 现价 | 当前行情价（默认固定显示在第一行，不计入 4 指标） |
| 2 | 涨跌额 | `现价 − 昨收` |
| 3 | 涨跌幅 | `(现价 − 昨收) / 昨收 × 100%` |
| 4 | 均价(成本) | `总成本 / 总克重`（该品种全部持仓合并） |
| 5 | 持仓收益 | `现价 × 克重 − 总成本`（浮动盈亏额） |
| 6 | 收益率 | `持仓收益 / 总成本 × 100%` |
| 7 | 今日盈亏 | `(现价 − 昨收) × 克重` |
| 8 | 累计收益 | `Σ卖出净得 + 持仓市值 − 累计投入` |

现价与涨跌额/涨跌幅在通知第一行固定展示（红涨绿跌），下方网格展示用户自选的 4 个指标（键值对）。品种无行情或无持仓时，对应数值显示 `--`。

## 3. 通知栏展示效果（Android 13+ 样式）

```
┌────────────────────────────────┐
│ 🪙 金脉 GoldPulse     [常驻]    │  ← 应用名 + 常驻标签
│ 浙商积存金  ▲ +3.42    900.10   │  ← 品种名 + 涨跌额 + 现价（固定行）
│ 均价(成本)  896.40  持仓收益 +185.0 │
│ 收益率     +0.41%   今日盈亏  -32.5 │  ← 用户自选 4 指标，2×2 网格
│ 更新于 13:42:05 · 每 10 秒刷新     │  ← 更新时间 + 频率说明
└────────────────────────────────┘
```

## 4. 技术架构

### 4.1 前台服务 + 持续通知

Android 要求前台服务必须显示常驻通知（onGoing），这正与功能契合：

- 方案选型：**`flutter_foreground_task`** 包（社区标准，支持常驻通知 + 周期回调 + 通知内容动态更新，无需自写原生 service）。
  - 备选：自写 Android Kotlin `ForegroundService` + MethodChannel（无第三方依赖，但工作量大、维护成本高）。**默认不采用**。
- 通知在服务回调（后台 isolate）中更新：每次周期触发 → 读 DB 最新行情 + 按品种持仓算指标 → 调用通知更新 API。

### 4.2 数据流

```
设置页（开关/品种/频率/指标）──写入──► SharedPreferences
                                        │ 服务读取配置
前台服务周期回调 ◄── Timer(频率) ────────┘
      │ 读 DB（PriceDao.latest + 该品种 holdings）
      ▼
计算 8 个指标（复用 Calculator / typeSummaries 口径）
      │
      ▼
更新常驻通知内容（现价+涨跌 + 自选 4 指标 + 更新时间）
```

- 行情数据复用现有轮询写入的本地 DB（`PriceDao.latest(code)`），不重复拉网。
- 收益计算复用 `Calculator`（`floatingProfit`/`todayProfit`/`cumulativeProfit`）与 `TypeAssetSummary` 聚合口径，保证与资产页一致。

### 4.3 Android 侧要求

- `AndroidManifest.xml`：声明 `FOREGROUND_SERVICE` 权限 + 前台服务（`flutter_foreground_task` 自带声明）。
- 通知权限（POST_NOTIFICATIONS）：main.dart 已申请，无需新增。
- 前台服务类型：`specialUse` 或 `dataSync`（Android 14+ 需声明 `foregroundServiceType`）。
- 电量：服务常驻后台有电量开销；刷新频率越低越省电（默认 10s）。

## 5. 配置存储（SharedPreferences key）

| key | 值 | 默认 |
|---|---|---|
| `notificationBarEnabled` | bool | false |
| `notificationBarKind` | `'au9999'/'accumulation'/'icbc'/'minsheng'` | `'accumulation'` |
| `notificationBarIntervalSeconds` | int | 10 |
| `notificationBarMetrics` | List<String>（指标 id，≤4） | `['avgCost','floatingProfit','profitRate','todayProfit']` |

## 6. 错误与边界处理

- 无持仓 / 无行情 / DB 为空 → 指标显示 `--`（不崩溃、不重复拉网）。
- 品种切换或配置变更 → 服务读取新配置，下一次周期生效（或立即重启通知）。
- App 被杀死后：前台服务由系统保持运行，通知继续更新（无需 App 在前台）。若用户强停服务则通知消失。
- 首次开启需在 Android 设置确认通知权限。

## 7. 测试策略

- 指标计算：8 个指标的纯函数单测（与 Calculator/资产页口径对齐）。
- 配置读写：SharedPreferences 读写 + 8 选 4 限制（>4 拦截）。
- Widget 测试：设置页开关/品种下拉/频率选择/指标多选（最多 4）交互。
- 通知更新：服务回调逻辑（读 DB → 算指标 → 构造通知文本）单元测试。
- 真机：开启后通知栏出现常驻通知，按频率刷新，内容与资产页收益一致。

## 8. 范围

**In scope**：常驻通知（单品种）、设置页开关/品种/频率/指标、指标计算、服务启停。
**Out of scope**（YAGNI）：多品种同时在通知显示、通知点按跳转、前台服务的详细样式自定义（图标/分组）、省电模式策略。
