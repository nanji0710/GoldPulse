方案要点
· 技术：Android 前台服务（foreground service） + 持续通知（onGoing）。前台服务常驻运行、系统不杀，定时从本地库取最新行情 + 按所选品种持仓计算收益 → 更新通知内容。关掉开关即停服。
· 品种：单选一个积存金（Au9999 / 浙商 / 工商 / 民生）。
· 指标池（8 选 4）：现价 · 涨跌额 · 涨跌幅 · 均价(成本) · 持仓收益 · 收益率 · 今日盈亏 · 累计收益。
· 频率：5 / 10 / 30 / 60 秒（独立于行情轮询频率，通知更新不用太频繁省电）。
· 开关入口：设置页新增「常驻通知栏」区块（总开关 + 品种 + 频率 + 指标）。
· 数据来源：复用现有行情轮询的 DB + 持仓（holdings/typeSummaries）——收益口径与资产页完全一致。
