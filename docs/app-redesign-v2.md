# GoldPulse 全 App 界面重构方案 v2

> 依据 ui-ux-pro-max 设计系统（Dark Mode/OLED + 金融仪表 + 高级金）对全部 6 个页面与共享组件做一致性优化。
> 主题 token：lib/constants/app_theme.dart 黑金 v2。日期：2026-08-04。

## 0. 设计语言（统一规范）

| 规范 | 值 |
|------|-----|
| 背景 | #0F172A（深海军蓝） |
| 卡片 | #1E293B，圆角 20，主卡用 heroGradient |
| 强调色 | 金 #D9A441（主操作/选中/涨跌胶囊） |
| 涨跌 | 红涨 #E5484D / 绿跌 #2E9E6B（国内习惯） |
| 数字 | tabular figures 等宽对齐 |
| 触控 | 目标 ≥44px，相邻间距 ≥8px |
| 状态 | 空态/加载/错误三态齐全，均有指引 + 行动点 |
| 底部弹层 | 统一拖拽把手 + 圆角 20 + 卡片底色 |

## 1. 首页（home）— 小改

现状：双行情卡 + 收益卡 + 刷新行（已达标）。
- [ ] 持仓空态：纯文本 → 图标 + 文案 + 「去添加」按钮（跳资产页）
- [ ] 状态胶囊防溢出：午间休市+恢复提示过长时允许换行

```
[Au9999 卡][浙商积存金 卡]
┌──────────────────────────────┐
│  💰 还没有持仓记录            │
│  录入第一笔黄金持仓，立即看到盈亏 │
│     [ 去添加持仓 ]            │
└──────────────────────────────┘
每 2 分钟刷新 · 下次 14:20:00（1m 30s 后）
```

## 2. 行情（market）— 重构（详见 market-page-redesign-v2.md）

价格头卡（实时流）→ 区间统计行 → 周期分段控件 + K线独立开关 → 图表卡（双轴刻度/渐变面积/触摸气泡/网格/色盲友好K线）→ 三态。

## 3. 资产（asset）— 中改

- [ ] 空态：图标 + 文案 + 「添加第一笔持仓」主按钮（金色）
- [ ] 持仓列表项：卡片内展示**实时浮动盈亏**（按持仓类型取价，红涨绿跌），替代纯 chevron
- [ ] 添加表单弹层：加拖拽把手；金额输入加单位前缀提示（g / 元/g）

```
[资产 ✓]
┌──────────────────────────────┐
│ 浙商积存金          ▲ +128.40 │
│ 50.00g · 成本 870.00 元/g     │
│ 浮动收益 +128.40 元（+0.30%） │
└──────────────────────────────┘
（空态）💰 还没有持仓 → [添加第一笔持仓]
```
